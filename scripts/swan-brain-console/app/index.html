Start here — what this console is

Twenty AI-built homepage designs (the "fleet") are competing to become the next SwanStudios front page. This console is the briefing room: the design rules they follow, their structural line-up, and an honest report of what the system can and cannot do yet.

Nothing here can break anything. The console is read-only and runs only on your machine — there is no button anywhere that writes to the site, the repo, or the learning engine.

The loop is three steps:

  1. — the rules every variant was built against.
  2. — then open a variant's Watch it move link to judge it live.
  3. — what the system saves today, and why.

The winner never ships from here: promotion happens as a normal reviewed commit, so every design, accessibility and review gate still applies. Links marked Watch it move open the live gallery — if one does not load, the gallery harness is not running: start it with npx vite --port 5199 from the frontend/ folder.

Glossary — the words this console uses
DECLARED_BLOCKED
The learning engine's own documentation declares durable writes locked until a signed security adapter exists. Expected today — not an error. (The console believes the docs; it cannot probe the gate itself. VERIFIED_BLOCKED would mean the console checked the lock directly; UNKNOWN means it can't tell and demands human review.)
Divergence tuple nav · hero · grid
The three structural choices that make a variant unique: where navigation lives, how the hero scene moves, how content grids. No two of the twenty share a tuple.
Archetype
A named page recipe (there are 22) from the design brain — e.g. "cinematic 3D scroll website".
Wildcard
Exactly one variant (v18) seeded with a deliberately alien idea, so the tournament can't converge on safe sameness.
Spec mode
The engine's persistence flag for generated specs. It is off by policy; the Doctrine tab reports the real value rather than assuming.
Canvas round
A judging batch of five variants — small enough that a three-second thumbnail pass is honest.

Canvas

Tournament rounds of five — small enough that a quick thumbnail pass is honest; the wildcard sits last. What to do here: walk the rounds in order, note which IDs survive, and use Watch it move on the survivors before deciding.

Copy

The language check. Phrases that read as AI filler are banned outright, and every stat resolves from your real marketing numbers — none are invented. What to do here: sanity-check tone; nothing on these pages should sound machine-written.

Engine

The Design Brain learning loop. It is fail-closed by design, and this panel reports that state rather than offering controls that cannot work. What to do here: nothing to operate — this tab exists so the console cannot lie to you about what is being saved.

Gates

Whether each declared gate has actually run, and what it said. A gate with no result, a stale result, a corrupt result and a simulated result are four different problems, and none of them is a green light. What to do here: read this before trusting any other number in the console — a gate that did not run is not a gate that passed.

Seats

Model seats are not wired in this build.

NOT BUILT — v1 fence. Seat selection lives in environment variables today, and the console deliberately does not wrap them yet: a picker implies the choice is verified, and the recorded Ox-as-Grok misfires show an env-var seat silently picks the wrong model. Building this panel needs a verified identity check first, not a dropdown.

Do today instead: ask the agent to verify which model a seat is actually serving before any paid run — the receipt names the exact check.

Judge

Pairwise judging: two variants side by side, your pick recorded. Rankings are kept in this browser only — nothing here is written to the repo or the learning engine. What to do here: work through the pairs; the ranking is the input the design decision needs, and it is cheaper than re-reading twenty pages.

Memory

Durable learning is not readable from here yet.

NOT BUILT — blocked upstream. The engine's memory is only writable through the fail-closed path shown on the Engine tab, so there is nothing new to browse. Showing an empty memory browser would imply the loop is running when it is not.

Do today instead: nothing is recorded yet — once the engine unlocks, design picks will start landing here without any extra step.

Ship

Promotion is a reviewed commit, never a console action.

NOT BUILT — by design. Promoting a variant means moving its import from the parked registry into a canonical route in a normal reviewed commit (DesignPlayground/README.md). A one-click promote button would bypass the design, accessibility, responsive and hostile-review gates that rule exist to enforce.

Do today instead: name the winning variant in chat — the agent promotes it through the full gate chain and hands you the receipt.
