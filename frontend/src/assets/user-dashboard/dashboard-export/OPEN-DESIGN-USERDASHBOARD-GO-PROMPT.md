Production context reference:

Do not redesign from scratch. Preserve the existing UserDashboard V3 / Crystalline Creator Observatory direction: dark-first SwanStudios luxury, crystalline glass panels, creator-style Home tab, XP/status beats, left rail, right rail, mobile bottom navigation, and premium social-fitness energy.

First pass scope:
- Home + shared dashboard shell first.
- Then show how the same system extends into Community, Reels/feed, Progress, Profile, Workouts, and Rewards.
- Do not replace every tab in this first pass.

Deliverables:
1. Interactive HTML prototype.
2. Handoff notes with component map, styled-components plan, mobile navigation plan, and mock/live-ready data contracts.

Mobile requirements:
- Mobile-first dashboard experience.
- No horizontal overflow at 300, 332, 390, and 430px widths.
- 44px minimum touch targets.
- Keep important actions reachable from the mobile bottom nav.

Implementation constraints:
- Use SwanStudios / Crystalline Creator Observatory style.
- Use Plus Jakarta Sans, Sora, Fira Code, and Cormorant Garamond if referencing typography.
- Keep WCAG contrast.
- Do not invent backend behavior.
- Do not imply automatic AI writes.
- Do not use yoga/meditation language; use training, workout, recovery, stretching, mobility, and flexibility.

If a file is inaccessible, report the exact missing file and continue only from accessible files.
