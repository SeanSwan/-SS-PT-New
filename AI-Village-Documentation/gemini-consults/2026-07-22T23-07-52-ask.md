#### 1. Refinement: Keyboard Container Focus State

The spec correctly makes the journey container focusable. However, it omits the visual styling for that focus state. A default browser outline is unacceptable for our brand. We will implement a signature Crystalline Swan focus glow.

**Action:** Apply the following styles to the container `<div>` with `tabindex="0"` using the `:focus-visible` pseudo-class. This ensures the glow only appears for keyboard navigators, not on mouse click, which is the modern accessibility best practice.

```css
/* In your styled-component for the journey container */
&:focus-visible {
  outline: 2px solid transparent; /* Remove default outline */
  outline-offset: 2px;
  box-shadow: 
    0 0 0 2px var(--obsidian-black, #0A0A0F), 
    0 0 0 4px var(--wing-purple, #8B5CF6), 
    0 0 12px 4px var(--wing-purple, #8B5CF6);
  transition: box-shadow 150ms cubic-bezier(0.4, 0, 0.2, 1);
}
```

**Rationale:** This multi-layered `box-shadow` creates our signature `Wing Purple` glow. The inner `obsidian-black` layer provides separation from the container's content, ensuring the glow feels external and intentional. The `cubic-bezier` curve provides a subtle, responsive feel as the focus state appears.

---

#### 2. Refinement: Scrim Gradient Polish

The current scrim gradient (`transparent` to `var(--obsidian-black)` at 78%) is functional but risks a hard, visible edge where the transparency ends. This can break the "enchanted" immersion. We will refine it for a more cinematic, ethereal fade.

**Action:** Replace the existing `linear-gradient` with a smoother, multi-stop version.

**Current:**
`linear-gradient(180deg, transparent, var(--obsidian-black, #0A0A0F) 78%)`

**Proposed Replacement:**
```css
/* Use RGBA for explicit alpha channel control in the gradient */
background: linear-gradient(
  180deg, 
  rgba(10, 10, 15, 0) 50%, 
  rgba(10, 10, 15, 1) 85%
);
```
*(Note: `rgba(10, 10, 15, ...)` is the explicit form of our `--obsidian-black` token.)*

**Rationale:** This new gradient starts its fade much higher up (at 50% of the container height) but completes it over a longer distance (ending at 85%). This creates a softer, more gradual falloff that feels less like a UI element and more like a natural vignette or atmospheric fog. It fully supports the "deep-ocean vault" aesthetic and ensures no hard lines distract from the video content.
