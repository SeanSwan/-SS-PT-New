### 1. Design Gaps

Claude, you missed a few critical UX/UI considerations in your plan:

*   **Interaction Blocking (Critical):** The plan doesn't mention `pointer-events`. If a user is rapidly liking posts or completing a workout, these animations *cannot* block the UI. The React Portal overlay must be strictly `pointer-events: none;`.
*   **Typography Strategy:** "Escalating text" can look incredibly cheesy if not styled correctly. We need a specific typographic hierarchy for the combo callouts that utilizes background-clip gradients and aggressive italics to convey motion.
*   **Responsive Scaling:** A "full-screen shockwave" built for 375px mobile will look like a tiny puddle on a 3840px ultrawide monitor. We must use `vmax` units for shockwaves so they scale proportionally across all 10 breakpoints.
*   **Fallback for `prefers-reduced-motion`:** Simply disabling the animation isn't enough. We need a graceful fallback: a beautiful, static glassmorphic toast notification that fades in and out over 2 seconds.
*   **Touch Targets for Toggles:** The Sound and Retro mode toggles must adhere strictly to our 44px minimum touch target rule for mobile-first accessibility.

### 2. Enhancement Opportunities

To elevate this from a standard feature to a best-in-class SwanStudios experience:

*   **The Odometer Effect:** Don't just pop the XP text. The user's actual total XP counter in the header/profile should roll up like a digital odometer or a vintage flip-clock while the particles fly toward it.
*   **Swan-Specific Combo Copy:** Ditch the Candy Crush "Nice/Amazing" copy. We are a cosmic fitness platform. The combo chain should be: **SPARK (3x) → IGNITE (5x) → BLAZING (10x) → SUPERNOVA (15x) → ECLIPSE (20x+).**
*   **Haptic Choreography:** Map `navigator.vibrate` exactly to the animation curves.
    *   XP Pop: `[10]` (Light tick)

*   **Particle Shapes:** No generic circles. Particles should be a mix of 4-point cosmic stars (✨), glowing cyan orbs, and subtle geometric swan feathers.

### 3. Architecture Recommendations

*   **Micro-interactions (XP Pops):** Use pure CSS `keyframes` within `styled-components`. Do *not* use Framer Motion for these. If a user triggers 20 XP pops in 5 seconds, React state + Framer Motion will cause layout thrashing on mobile. Render them as lightweight DOM nodes with CSS transforms.
*   **Macro-interactions (Level Up):** Use a `<canvas>` element managed by a lightweight 2D context script (or a library like `tsparticles` customized heavily) for the Constellation Swan. DOM elements cannot handle 500+ particles smoothly on a 320px device.
*   **Z-Index Architecture:** Create a new token tier for this.
    *   `z-index: 9000` (Modals/Overlays)
    *   `z-index: 9999` (Celebration Portal - `pointer-events: none`)
