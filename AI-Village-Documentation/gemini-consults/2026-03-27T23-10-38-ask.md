### 3. TECHNICAL ARCHITECTURE: BEATING THE RENDER TIMEOUT
**The Verdict:** Polling is unacceptable for a premium SaaS. Render's 30-second timeout will kill standard HTTP requests for complex AI generation. 

**The Mandate:** We are implementing **SSE (Server-Sent Events) via the Fetch API**. This streams the response chunk-by-chunk, bypassing the 30s timeout and providing a premium, real-time typing effect.

**Backend Implementation (Node.js/Express):**
```typescript
// Express Route for AI Coaching Stream
app.post('/api/ai/coach-stream', async (req, res) => {
  res.setHeader('Content-Type', 'text/event-stream');
  res.setHeader('Cache-Control', 'no-cache');
  res.setHeader('Connection', 'keep-alive');

  try {
    const stream = await geminiModel.generateContentStream({
      contents: buildContextWindow(req.body.history), // See history note below
      systemInstruction: NASM_SYSTEM_PROMPT
    });

    for await (const chunk of stream) {
      const text = chunk.text();
      // Send chunk to client
      res.write(`data: ${JSON.stringify({ text })}\n\n`);
    }
    res.write('data: [DONE]\n\n');
    res.end();
  } catch (error) {
    res.write(`data: ${JSON.stringify({ error: 'Stream failed' })}\n\n`);
    res.end();
  }
});
```
