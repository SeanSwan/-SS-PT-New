```markdown
## 🧹 CRYSTALLINE VAULT: FILE CLEANUP PROTOCOL
**Trigger:** User commands "do file cleanup protocol" OR AI detects workspace bloat (e.g., test artifacts > 100MB).

### 1. TARGET CATEGORIES & ACTIONS
- **Test Artifacts (PURGE):** `playwright-report/`, `test-results/`, `*.last-run.json`, Playwright traces/screenshots. *Action: Delete immediately. Do not archive.*
- **Build Bloat (PURGE):** `dist/`, `build/`, `node_modules/.cache/`. *Action: Delete immediately.*
- **Dead/Duplicate Code (ARCHIVE):** Unused components, deprecated UI files, redundant utility functions.
- **AI Village Logs (ARCHIVE):** Old AI conversation logs or deprecated planning files.

### 2. STRICT SAFETY RULES (NEVER DELETE)
- **Untouchable Directories:** `src/` (unless explicitly archiving dead code), `server/`, `database/migrations/`, `database/seeders/`.
- **Untouchable Files:** `*.config.*`, `.env*`, `package.json`, `CLAUDE.md`.
- **Git Rule:** Only clean untracked files OR safely `git rm` files after adding them to the Archive Map.

### 3. THE ARCHIVE MAP (`.swan/archive-map.json`)
Never delete potentially useful code. Move it to `.swan/archive/` and log it in the JSON manifest.
**Format:**
```json
{
  "timestamp": "2024-03-20T12:00:00Z",
  "originalPath": "src/components/OldSwanButton.tsx",
  "archivePath": ".swan/archive/OldSwanButton_20240320.tsx",
  "reason": "Replaced by CrystallineButton. Retained for reference.",
  "retrievalCommand": "cat .swan/archive/OldSwanButton_20240320.tsx"
}
```

### 4. EXECUTION WORKFLOW
1. **Scan:** Identify bloat (Test dirs > 100MB) or scan for dead files.
2. **Map:** Append entries to `.swan/archive-map.json` for code/logs. (Skip mapping for test/build artifacts).
3. **Execute:** Move mapped files to `.swan/archive/`. Run `rm -rf` on test/build artifacts.
4. **Gitignore Sync:** Ensure `playwright-report/`, `test-results/`, and `.swan/archive/` are explicitly listed in `.gitignore` to prevent re-tracking.
5. **Report:** Output a concise terminal summary: `[Crystalline Vault] Cleared X MB of test artifacts. Archived Y files.`
```
