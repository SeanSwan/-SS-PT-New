### 1. PILLAR SWITCHING UX: Segmented Control (Option A Refined)
We will use a horizontal segmented control (pill toggle). It is the most scannable and requires zero extra clicks. However, at a 320px master pane width, 4 text labels will truncate. 

**Design Spec:**
- **Container:** `background: ${theme.colors.Carbon};` (`#141419`), `border-radius: 12px`, `padding: 4px`, `display: flex`, `height: 44px` (strict touch target).
- **Items (4):** Equal width (`flex: 1`). 
- **Typography:** `font-family: 'Sora', sans-serif; font-size: 12px; font-weight: 600;`
- **Inactive State:** `color: ${theme.colors.SwanLavender};` (`#4070C0`), transparent background.
- **Active State:** 
  - `background: ${theme.colors.Graphite};` (`#1A1A24`)
  - `color: ${theme.colors.FrostWhite};` (`#E0ECF4`)
  - `border-radius: 8px`
  - `box-shadow: 0 2px 8px rgba(0, 0, 0, 0.4)`
- **Responsive Behavior:** Below 768px, drop the text and use strictly recognized icons (e.g., Users for Roster, Chart for Growth, Building for Studio, Chat Bubble for Comms) centered in each pill.

### 2. DETAIL VIEW EMPTY STATE: The "Apex Command" Dashboard (Option B)
An empty screen is wasted real estate. When no client is selected, the right pane becomes the **Apex Command Center**. It must feel like a high-end luxury vault of data.

**Design Spec:**
- **Hero Greeting:** `font-family: 'Cormorant Garamond', serif; font-style: italic; font-size: 32px; color: ${theme.colors.FrostWhite};` (e.g., *"Command your day, Trainer."*)
- **Background:** `Obsidian Black` (`#0A0A0F`) with a massive, subtle Swan logo watermark centered (`opacity: 0.02`, `pointer-events: none`).
- **Content Grid (2 Columns at 1024px+):**
  - **Left Column (Action):** "Today's Vanguard" — A timeline of today's appointments and clients who are 30+ days overdue for a weigh-in (flagged with `Gilded Fern #C6A84B` accents).
  - **Right Column (Pulse):** "Studio Pulse" — High-level metrics using `Arctic Cyan #50A0F0` for the data visualizations (bar charts/sparklines of weekly engagement). *Remember: Arctic Cyan is for data only, no glow.*

### 3. TRANSITION ANIMATIONS: The "Crystalline" Motion Curve
We reject generic linear animations. Everything must feel fluid, deliberate, and premium.

**Design Spec:**
- **Master Pane Collapse:** `transition: width 300ms cubic-bezier(0.4, 0, 0.2, 1);` (Confirmed).
- **Client Selection (Detail Pane Population):** 
  - **Animation:** Fade-in + subtle slide-up to feel like data is rising to the surface.
  - **CSS:** `animation: surfaceRise 350ms cubic-bezier(0.2, 0.8, 0.2, 1) forwards;`
  - **Keyframes:** `from { opacity: 0; transform: translateY(12px); } to { opacity: 1; transform: translateY(0); }`
- **Tab Switching (Within Detail View):** 
  - **Animation:** Instant layout snap with a rapid cross-fade. Do *not* slide horizontally; varying content heights cause layout thrashing.
  - **CSS:** `transition: opacity 200ms ease-in-out;`
- **Pillar Switching (Master List):** 
  - **Animation:** Staggered list population.
  - **Implementation:** Use a slight stagger delay on the list items (`animation-delay: calc(var(--item-index) * 30ms);`) using the `surfaceRise` keyframes above.

### 4. CLIENT CARD SELECTION STATE: Dual-Tone Glow Logic
Your proposal is close, but we must strictly adhere to the Crystalline Swan dual-glow logic. If the accent is Wing Purple, the glow *must* be Ice Wing to create that signature theme tension.

**Design Spec (Styled Component snippet):**
```css
background: ${props => props.$isSelected ? '#1A1A24' : '#141419'}; /* Graphite vs Carbon */
border-left: 3px solid ${props => props.$isSelected ? '#8B5CF6' : 'transparent'}; /* Wing Purple */
transition: all 200ms ease;

/* The Crystalline Dual-Glow */
box-shadow: ${props => props.$isSelected 
  ? 'inset 6px 0 12px -4px rgba(96, 192, 240, 0.25)' /* Ice Wing inner glow */
  : 'none'};

/* Text color shift */
color: ${props => props.$isSelected ? '#E0ECF4' : '#4070C0'}; /* Frost White vs Swan Lavender */
```

### 5. SEARCH & FILTER PLACEMENT: The 320px Constraint
At 320px, a full toolbar is too cluttered. We will use a split input/icon-button layout.

**Design Spec:**
- **Layout:** Flex row, `gap: 8px`, `margin-bottom: 16px`.
- **Search Input:** `flex: 1`. Height 44px. Background `Carbon #141419`. Left-aligned search icon (`Swan Lavender #4070C0`). Font: `Sora 14px`.
- **Filter Button:** Fixed `width: 44px`, `height: 44px`. Background `Carbon #141419`. Icon: Sliders/Filter.
- **Filter UX:** Clicking the filter button opens a dropdown menu (`Graphite #1A1A24` background, `border: 1px solid #003080` Royal Depth).
- **Sort/Filter Options:** 
  - Sort: Engagement Score (High/Low), Name (A-Z), Last Active.
  - Filter: Tier (Premium/Standard), Status (Active/At-Risk).

### 6. KEYBOARD NAVIGATION: Pro-Tier Accessibility
Trainers managing 50+ clients need to fly through this UI without a mouse. 

**Design Spec:**
- **`Arrow Up/Down`:** Moves visual focus (a subtle `Royal Depth #003080` outline) up and down the master list. *Crucial: Do not auto-fetch detail data on arrow key to prevent API spam.*
- **`Enter`:** Selects the currently focused client, triggering the `surfaceRise` animation in the detail pane.
- **`Escape`:** 
  - Desktop: Deselects the current client (returns to Apex Command empty state).
  - Mobile (<1024px): Dismisses the full-screen detail overlay (translates X back to 100%).
- **`Cmd/Ctrl + /` (Slash):** Global shortcut to focus the Master Pane Search input. (Since `Cmd+K` is reserved for our AI assistant, `/` is the standard fallback for search focus, universally recognized by power users).
