### A. CLIENT CARD QUICK ACTIONS (Ratified with Contextual UX)
**CEO Proposal:** Swap Weigh-in for View Workouts. Make Weigh-in contextual if overdue.
**CTO Ruling:** **APPROVED.** Brilliant UX. Trainers live in the workout history. The contextual swap elevates this from a static UI to a "smart" assistant.

**Design Spec:**
*   **Action 1:** Message (Icon: Chat bubble)
*   **Action 2:** Log Workout (Icon: Plus/Dumbbell)
*   **Action 3 (Default):** View Workouts (Icon: Eye or Clipboard)
*   **Action 3 (Contextual Alert - Overdue > 30 days):** Scale icon (Weigh-in) with a pulsing alert dot.
*   **Alert Dot Styling:** `width: 8px; height: 8px; border-radius: 50%; background: #C6A84B;` (Gilded Fern for warning) or `#C92A54` (Crimson Frost if critically overdue > 60 days). Positioned `top: -2px; right: -2px;` on the icon button relative container.

### B. MASTER PANE WIDTH (Ratified with Collapsible Architecture)
**CEO Proposal:** 320px width, collapsible to 64px (VS Code style).
**CTO Ruling:** **APPROVED.** 380px was too greedy. 320px hits the golden ratio perfectly at 1024px+. The 64px collapsed state is perfect for deep-work focus (like the Body Map).

**Design Spec (Sidebar Transitions):**
*   **Expanded Width:** `320px`
*   **Collapsed Width:** `64px`
*   **Transition Curve:** `transition: width 300ms cubic-bezier(0.4, 0, 0.2, 1);` (Smooth, hardware-accelerated feel).
*   **Collapsed State UI:** Hide client names and stats (`opacity: 0`, `pointer-events: none`). Center the Client Avatar (40x40px). Keep the online/active status dot visible on the avatar.
*   **Hover in Collapsed State:** Show a tooltip with the Client Name (`font-family: 'Sora'`, `background: #1A1A24` Graphite, `color: #E0ECF4` Frost White).
