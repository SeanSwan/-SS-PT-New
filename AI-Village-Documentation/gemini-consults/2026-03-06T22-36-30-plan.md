Here is my authoritative design direction for the Boot Camp Class Builder.

---

### 1. Design Gaps in Your Plan

*   **Environmental Glare & "Floor Mode"**: You missed the physical reality of the gym. Tablets on a gym floor face harsh overhead lighting. The deep Galaxy Core (`#0a0a1a`) is beautiful for the *Builder*, but we need a high-contrast, ultra-legible **"Floor Mode"** toggle for active class execution.
*   **Sweaty-Hand Ergonomics**: 44px is our baseline touch target, but for the active Boot Camp tablet view, primary actions (Start Timer, Next Station, Swap Exercise) must be **64px minimum**. 
*   **Cognitive Overload in Modifications**: Presenting 4 difficulty tiers *plus* 5 joint modifications for 15 exercises simultaneously will create a wall of text. We need progressive disclosure.
*   **Offline Resilience**: Gym WiFi is notoriously spotty. The UI must gracefully handle offline states without breaking the glassmorphic aesthetic (e.g., a subtle pulsing amber border indicating local caching).

---

### 2. Enhancement Opportunities (The Premium Feel)

*   **The "Holographic" Space Mapper**: When Sean uploads the 360 video, do not just show a loading spinner. We will use a **"Nebula Scan" effect**: a wireframe grid overlay that sweeps across the video, transitioning into a 2D glassmorphic top-down blueprint of the gym. 
*   **Magnetic Timeline**: Borrowing from Apple Final Cut Pro, the 50-minute class timeline should be a horizontal, magnetic track. When an exercise is dragged in, it snaps into place, automatically recalculating the 35/40/30-second intervals and visually pushing other blocks down the timeline.
*   **Haptic & Visual Weight**: Heavy setup exercises should *feel* heavy in the UI. We will use denser typography and a deeper Cosmic Purple border for heavy stations, contrasting with lighter, brighter Swan Cyan for cardio finishers.

Here are the answers to your design questions with exact implementation instructions.

#### Q2: The Printable Class Sheet
**Directive:** Strip the Galaxy theme entirely for print. It must be a high-utility, ink-saving grid.
*   **CSS**: Wrap the component in `@media print`.
*   **Layout**: 3-column CSS Grid. 
*   **Typography**: Switch from our UI sans-serif to a highly legible, dense font (e.g., Inter SemiBold). Black text (`#000000`) on white (`#FFFFFF`).
*   **Visual Hierarchy**: 
    *   Station numbers: `font-size: 24pt; font-weight: 800; border-bottom: 2px solid #000;`
    *   Pain Mods: Do not print text. Use standardized icons (a knee icon, a shoulder icon) next to the exercise name with the modified exercise name in `font-size: 10pt; font-style: italic;`.

#### Q3: Difficulty Tiers & Pain Modifications (Visual Hierarchy)
**Directive:** Progressive Disclosure via "Pill Clusters".
*   On the main tablet view, an exercise block (e.g., "Goblet Squat") shows small, glowing indicator dots if mods exist.
*   **Interaction**: Tapping the exercise expands a glassmorphic drawer (`framer-motion` height animation, `spring` stiffness 300, damping 30).
*   **Color Coding**:
    *   Base: White text.
    *   Easy/Mod: `color: #A0AEC0;` (Muted)
    *   Hard: `color: #FF4757;` (Alert Red)
    *   Low-Impact Advanced: `color: ${theme.colors.swanCyan}; text-shadow: 0 0 8px rgba(0,255,255,0.4);`
*   **Pain Mods**: Display as a horizontal scrollable row of chips. `border-radius: 16px; padding: 6px 12px; background: rgba(255,255,255,0.05);`.

#### Q4: Space Analysis UX
**Directive:** The "Holographic Blueprint".
*   **Upload State**: A dashed border dropzone `border: 2px dashed rgba(0, 255, 255, 0.3);`.
*   **Processing State**: Overlay a scanning line `animation: scan 2s cubic-bezier(0.25, 1, 0.5, 1) infinite;` where the line is a 2px Swan Cyan gradient.
*   **Result State**: Render the Gemini output as a 2D top-down map. Use SVG. 
    *   Obstacles: Red hatched patterns.
    *   Usable Zones: `fill: rgba(0, 255, 255, 0.1); stroke: #00FFFF;`.
    *   Station Nodes: Pulsing dots (`width: 12px; height: 12px; border-radius: 50%; background: #00FFFF; box-shadow: 0 0 12px #00FFFF;`).

#### Q5: Animations & Transitions
**Directive:** Fluid, premium, and purposeful. No bouncy, cheap effects.
*   **Drag & Drop**: When picking up an exercise card, scale it up slightly (`scale: 1.02`), increase the drop shadow (`box-shadow: 0 20px 40px rgba(0,0,0,0.5)`), and apply a subtle rotation (`rotate: 1deg`).
*   **AI Generation**: When the AI auto-generates the overflow/backup plan, do a "cascade reveal". The new stations should fade and slide in from the top with a staggered delay (`transition: { staggerChildren: 0.05 }`).
*   **Easing Curve**: For all UI panel slides, use `cubic-bezier(0.16, 1, 0.3, 1)` (a custom Apple-like ease-out).
