### 1. Design Gaps (What You Missed)

*   **The "Value Proposition" Gap:** Parents won't request an enhancement if they don't know what it looks like. The UI currently lacks a visual demonstration of "Raw vs. Enhanced."
*   **Action Hierarchy:** "Free Download" and "★ Request Enhancement" cannot carry the same visual weight. The enhancement CTA must be the primary visual draw, while the download is a secondary, frictionless action.
*   **Loading Architecture:** Uploading hundreds of high-res sports photos requires a specific loading strategy. Standard spinners are unacceptable. We need a progressive blur-up (LQIP - Low Quality Image Placeholder) strategy.
*   **Mobile Cart UX:** A "slide-out panel" for the enhancement cart works on desktop, but on mobile, we need a persistent, floating bottom bar (like a food delivery app) showing "X Photos Selected" so parents don't lose context while scrolling.
*   **Accessibility (a11y):** Lightbox navigation must support keyboard arrows (`ArrowLeft`, `ArrowRight`, `Escape`). Focus must be trapped inside the lightbox when open.

---

### 2. Enhancement Opportunities (Elevating to Premium)

**A. The "Cosmic Gate" (Password Entry)**
Do not use a standard modal for the password gate. 
*   **Design:** The background should be a full-viewport, heavily blurred collage of the event photos (`filter: blur(40px) brightness(0.3)`). 
*   **Surface:** The entry form sits in the center on a premium glassmorphic card (`background: rgba(10, 10, 26, 0.6); backdrop-filter: blur(24px); border: 1px solid rgba(0, 255, 255, 0.15);`).

**B. The "Before/After" Interactive Tooltip**
When a user first hovers over (or taps) the "★ Request Enhancement" button, trigger a micro-interaction: a tiny, auto-playing split-screen slider showing a dull, flat photo transforming into a vibrant, color-graded SwanStudios masterpiece. This educates the user instantly.

**C. Justified Cinematic Grid (Not Masonry)**
Sports photos are predominantly landscape. Masonry (Pinterest-style) creates jagged, uneven horizontal lines. We will use a **Justified Grid** (Flickr/Google Photos style) where rows have a strict horizontal alignment, scaling images to fit the row height. This feels cinematic and organized.

**D. The "Cosmic Spark" Animation**
When a parent taps the Enhancement Star, it shouldn't just change color. It needs a Framer Motion spring-physics pop, emitting a subtle `#00FFFF` to `#7851A9` particle burst.

### 3. Architecture Recommendations

*   **Animation Engine:** Use **Framer Motion** for all layout shifts, lightbox orchestrations, and the cart slide-out. Use standard CSS `transition` for simple hover states.
*   **Styled-Components Pattern:** Use transient props (e.g., `$isSelected`, `$isEnhanced`) to prevent React from leaking styling props to the DOM.
*   **Theme Token Strategy:** 
    *   `theme.colors.core`: `#0a0a1a`
