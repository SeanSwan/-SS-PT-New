### 2. Responsive Behavior (10 Breakpoints)

*   **Mobile (320px, 375px, 430px)**:
    *   Tabs become a horizontally scrollable row (`overflow-x: auto`, `scroll-snap-type: x mandatory`). Hide scrollbars.
    *   KPI Cards stack `1fr` (1x4 grid).
    *   Tax Calculator and Last Order stack vertically.
    *   Tables transform into "Card Lists" (each row becomes a stacked card) to prevent horizontal scrolling nightmares.
*   **Tablet (768px, 1024px)**:
    *   KPI Cards become a 2x2 grid.
    *   Tax Calculator (1fr) and Last Order (1fr) sit side-by-side.
    *   Tables return to standard row format but hide non-essential columns (e.g., hide exact timestamps, keep dates).
*   **Desktop (1280px, 1440px, 1920px)**:
    *   Full layout as specified in Section 1.
    *   KPI Cards 4x1 grid.
*   **Ultra-Wide (2560px, 3840px)**:
    *   Wrap the entire dashboard in a max-width container (`max-width: 1600px; margin: 0 auto;`) to prevent extreme eye-travel.

---

### 3. Animations & Interactions

*   **Tab Switching**: Crossfade content (`opacity 0 -> 1` over 250ms, `ease-out`). The active tab gets a bottom border that animates in width from `0%` to `100%` using `cubic-bezier(0.16, 1, 0.3, 1)`.
*   **Hover States (Glass Cards)**:
    *   `transform: translateY(-4px);`
    *   `box-shadow: 0 12px 32px rgba(0, 0, 0, 0.4), 0 0 0 1px rgba(0, 255, 255, 0.2);`
    *   Transition: `all 300ms cubic-bezier(0.25, 0.8, 0.25, 1)`
*   **SwanToggle (Active/Inactive)**:
    *   Track background transitions from `#333` to `#00FFFF`.
    *   Knob translates `20px` with a spring-like easing `cubic-bezier(0.34, 1.56, 0.64, 1)`.
*   **Loading State**: Deep space shimmer. `linear-gradient(-45deg, rgba(255,255,255,0.02) 40%, rgba(255,255,255,0.08) 50%, rgba(255,255,255,0.02) 60%)`. Animate background position.

---

### 4. Accessibility

*   **Touch Targets**: Minimum `44x44px` enforced on all tabs, toggles, and table rows.
*   **ARIA**:
    *   Tab container: `role="tablist"`
    *   Tab buttons: `role="tab"`, `aria-selected={isActive}`, `aria-controls="panel-id"`
    *   Toggles: `role="switch"`, `aria-checked={isActive}`
*   **Focus Management**: `&:focus-visible { outline: 2px solid #00FFFF; outline-offset: 4px; border-radius: 4px; }`
*   **Reduced Motion**: Wrap animations in `@media (prefers-reduced-motion: reduce) { transition: none; animation: none; }`
