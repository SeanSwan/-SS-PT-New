## 3. Responsive Behavior (10 Breakpoints)

*   **320px (iPhone SE):** 1-column grid. Pill strip text `12px`. Bottom nav icons only.
*   **375px / 430px (Standard Mobile):** 1-column grid. Bottom Nav active. AI Terminal as bottom sheet.
*   **768px (iPad Mini):** 2-column grid for forms. Bottom Nav transitions to Left Sidebar (collapsed to 80px width). AI Terminal becomes a collapsible right-side panel (320px wide).
*   **1024px+ (Desktop):** 3-pane Boot Camp builder activates. Left Sidebar expands to 240px. Particles/heavy glassmorphism re-enabled.

---

## 4. Animations & Interactions

*   **Easing Curve (The "Swan Glide"):** `cubic-bezier(0.32, 0.72, 0, 1)` - Use this for ALL UI transitions. It provides a fast, responsive snap that settles smoothly.
*   **Pill Tap:** `transform: scale(0.96)` on `:active` with `0.1s` duration.
*   **AI Terminal Swipe-Up:** `transition: transform 0.4s cubic-bezier(0.32, 0.72, 0, 1)`.
*   **Skeleton Loading:** Shimmer effect using `linear-gradient(90deg, rgba(255,255,255,0) 0%, rgba(96,192,240,0.1) 50%, rgba(255,255,255,0) 100%)` moving at `1.5s` infinite.

---

## 5. Accessibility

*   **ARIA:** Use `role="tablist"` for the Pill Strip and `role="tab"` for individual pills. Use `aria-selected="true"` on the active pill.
*   **Contrast:** Ice Wing `#60C0F0` on Midnight Sapphire `#002060` exceeds WCAG AA (4.5:1).
*   **Reduced Motion:** Wrap animations in `@media (prefers-reduced-motion: reduce) { transition: none; animation: none; }`.
