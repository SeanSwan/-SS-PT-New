### 2. The React.memo + useCallback vs. $active Prop Re-evaluation
You are confusing React's Virtual DOM reconciliation with CSS DOM repaints.
* **Keep `React.memo` and `useCallback`:** The parent component (AIAssistantDrawer) is likely receiving rapid state updates (e.g., transcript streaming). We *must* memoize `ContextBar` to prevent React from unnecessarily diffing the entire pill list on every keystroke/spoken word.
* **The REAL Design Issue:** You mentioned using `font-weight: 500/600` for active states. **Absolutely not.** Changing font-weight on hover/active causes layout shifts (reflows) because the text physically expands, pushing adjacent elements around. This is classic "AI slop" UI and feels incredibly cheap.

**The Fix:** Keep the font-weight static at `500`. Indicate the `$active` state using our Swan Cyan and a text-shadow glow. The styled-component re-evaluating the CSS class is perfectly fine and highly performant if it doesn't trigger a layout reflow.

```typescript
// ContextPill styled-component
font-weight: 500;
color: ${props => props.$active ? '#00FFFF' : '#E0ECF4'};
text-shadow: ${props => props.$active ? '0 0 8px rgba(0, 255, 255, 0.4)' : 'none'};
background: ${props => props.$active ? 'rgba(120, 81, 169, 0.2)' : 'transparent'}; /* Cosmic Purple tint */
border: 1px solid ${props => props.$active ? 'rgba(0, 255, 255, 0.3)' : 'rgba(224, 236, 244, 0.1)'};
transition: all 0.3s cubic-bezier(0.25, 0.46, 0.45, 0.94);
```
