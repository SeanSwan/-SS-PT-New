### Layout Decision: Option C (Structural Split Desktop / Sticky Bottom Console Mobile)
We are going with a highly refined version of **Option C**. 
- **Desktop (1024px+)**: A structural 30% right-side panel. It is part of the CSS Grid layout, meaning it *pushes* dashboard content rather than overlaying it. 
- **Mobile (320px - 768px)**: A persistent, sticky bottom command console. The input and `DictationOrb` are *always* visible. When focused or swiped up, it expands into an 85vh bottom sheet using fluid spring physics. Every pixel on a 320px screen is sacred; we cannot afford a persistent 30% vertical split here.

### 3. Responsive Behavior (10 Breakpoints)

*   **320px, 375px, 430px (Mobile)**: Panel is docked to the bottom. Height is `88px` collapsed (just input + orb + 1 line of latest insight). Expands to `85vh` on tap/swipe. `DictationOrb` is exactly `56x56px` to ensure a massive, flawless touch target during gym floor sessions.
*   **768px (Tablet Portrait)**: Bottom docked, but expands to `60vh`. Max-width of the expanded sheet is `600px` centered, to prevent absurdly long text lines.
*   **1024px (Tablet Landscape / Small Laptop)**: Transitions to Option C. Right-side structural panel. Width is fixed at `320px`. Main dashboard grid adjusts to `1fr 320px`.
*   **1280px, 1440px (Standard Desktop)**: Panel width scales to `380px`. `DictationOrb` scales down to `48x48px` (mouse precision requires less area).
*   **1920px, 2560px (Large Desktop)**: Panel width caps at `420px`. Font sizes scale up slightly using `clamp()`.
*   **3840px (4K Ultrawide)**: Panel width caps at `480px`. Dashboard content centers.

---

### 4. Animations & Interactions

*   **Easing Curve**: `cubic-bezier(0.16, 1, 0.3, 1)` (Premium Apple-like spring).
*   **Mobile Expansion**: `transform: translateY(0)` from `translateY(calc(100% - 88px))`. Duration: `400ms`.
*   **DictationOrb Pulse**: When active (listening), the orb scales to `1.05` and pulses a Wing Purple `#8B5CF6` shadow.
*   **Message Reveal**: New AI messages slide up `10px` and fade in `opacity: 0 -> 1` over `300ms`.
*   **Hover States**: User bubbles subtly shift `transform: translateY(-1px)` and increase shadow opacity.

---

### 5. Accessibility

*   **ARIA**: The chat area must have `role="log"` and `aria-live="polite"`. The DictationOrb needs `aria-label="Start voice dictation"`.
*   **Keyboard**: On mobile, when expanded, focus must be trapped within the bottom sheet. `Escape` key closes the sheet.
*   **Reduced Motion**: `@media (prefers-reduced-motion: reduce)` must disable the spring animations and orb pulsing, falling back to instant state changes or simple opacity fades.
