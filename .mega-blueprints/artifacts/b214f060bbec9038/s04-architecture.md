All four consumers (Planner V1, Planner V2, Bootcamp library, NASM logger) distinguish these states:

| State | Visible result and action |
| --- | --- |
| Initial loading | Existing skeleton/spinner and Loading exercise library status; never a no-results claim |
| Initial error | Exercise library unavailable, readable error and keyboard-accessible Try again; never clear filters or erase draft |
| Successful empty catalog | No exercises available yet with Retry; no suggestion that typing will create catalog content |
| Ready, filters empty | No exercises match current filters with clear-filter/search action where already provided |
| Ready with matches | Existing virtualized rows, count and add/detail behavior |
| Refreshing cached catalog | Preserve visible filtered rows and current query; Updating library status |
| Refresh failed with cache | Preserve filtered rows, Library may be out of date notice and Try again; error not hidden just because rows exist |
| Search pending | Searching status/aria-busy; an earlier result count must not be announced as final |
