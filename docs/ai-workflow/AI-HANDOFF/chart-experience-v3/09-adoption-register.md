## Cohort receipt template

For every chart renderer, record exact file, ID, route/JSX mount, role, hook/API/model,
frame/theme imports, visual grammar, states, controls, unit/time semantics, tier/privacy,
source-detail behavior, tests and before/after screenshots. Classify canonical / legacy /
dormant / competing; ambiguous blocks that chart. Zero new competing frame/theme sources.
Use the complete inventory row schema and U01–U12 gates in
[the approved uniformity contract](10-approved-uniformity.md). The cohort list is a discovery
seed, not a substitute for one row per mounted chart occurrence.

Migration guards become blocking only on each successfully migrated scope. Tests cover palette,
portal tokens, measured width, motion, interactive table and action handlers. Do not turn guards
off to make old code green; unmigrated scopes remain named backlog, not concealed exceptions.

## Scope completion statements

- After C1: “Client progress V3 implemented and verified”; not “all charts unified.”

  unexplained live consumer, and every row has a current receipt/test result.

the client redesign becomes attractive. It is not authority for Luna to improvise unfamiliar
