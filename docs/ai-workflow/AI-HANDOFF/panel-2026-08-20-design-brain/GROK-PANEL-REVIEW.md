# Hostile review — ranked findings

## 1. The audit treats an unread-ledger embarrassment as the quality bottleneck, then prescribes more unread reports
**CLAIM.** P0 “close the learning loop” then P0 “Playwright Visual Director” is the same disease the audit diagnoses: artifacts and prose that nothing is forced to consume, aimed at the wrong causal layer. The primary slop engine is generation-time mode collapse into web-template grammar, adjective-doctrine satisfaction, and blind markup emission. Memory and post-hoc VLM critique do not sit on that path.

**EVIDENCE/REASONING.** Known facts: ledger writer exists, zero consumers, no `taste.profile.json`, no visual-critique agent, doctrine admits fictional enforcement. That is a real process smell. It is not why the next page is a dark 3-card hero with glow. LLMs emit the highest-probability SaaS page (hero / cards / social proof / CTA), then satisfy “cinematic / crystalline / sapphire” as tokens (dark bg, blur, bloom, gold hairline). A distilled profile injected into a pre-brief only changes the prompt text. The audit’s own acceptance test admits this: “changing the profile fixture changes the generated pre-brief.” Brief ≠ pixels. That test would have passed in every failed “next-slice” that earned REVISE.

The Visual Director spec is a folder tree plus a report schema (Keep/Fix/Elevate/Wildcard, 5 viewports, states, DOM, computed styles). That is a constitution for a critic, not a critic. It will land as JSON/markdown next to the unread ledger. The audit forbids “one fake beauty score” then offers no reliability mechanism except structured prose. VLMs are calibrated to sound like art directors; they are not calibrated to Sean. Same-family self-critique will bless its own tropes (glass, bento, gradient mesh).

Ratings 4.5 / 2.5 / 1.5–2 are unfalsifiable self-scores. The constitution is not 4.5/5: a rulebook that claimed unbuilt enforcement is a contaminated rulebook. Adjective doctrine is part of the slop pipeline; the audit never puts it on the stand.

**CONCRETE FIX.** Reorder ruthlessly. (1) Constrain generation with a layout IR + slop-skeleton denylist before JSX. (2) Mechanical inspector + receipt-gated router + Fix-apply-verify. (3) Exemplar vault so “good” is a picture, not an adjective. (4) Surface-typed materials on the existing Forge. (5) Taste consumer tested on IR/screenshot deltas, not brief diffs. Delete unenforceable adjectives from runtime prompts; keep them in a human brand book only. Ban any new `scripts/design-brain/*` tree that does not have a caller in the Atelier path in the same PR.

## 2. Root cause of AI slop is mechanistic, and the audit’s triad is incomplete
**CLAIM.** “No material pack / no rendered critique / open taste loop” is a partial theory. Slop is a stack of mechanisms. Highest-leverage interventions are generation-time, measurable, and negative-constrained. Post-hoc seeing and memory are secondary.

**EVIDENCE/REASONING.**

| Mechanism | What the model actually does | Why doctrine fails | Highest-leverage counter |
|---|---|---|---|
| **Template prior collapse** | Samples the web-UI mode: hero, 3 cards, testimonial row, CTA band | “Structurally distinct” in prose still maps to one grammar with different adjectives | Layout IR + skeleton hash denylist + pairwise distance gate *before* compile |
| **Adjective → token substitution** | “Crystalline atmosphere” → sapphire-800, glow, noise overlay | More doctrine adds more adjectives to substitute | Replace runtime adjectives with exemplars, budgets, forbidden patterns |
| **Blind markup emission** | Writes JSX/CSS as text; first pixels appear after Playwright | Critique after the fact cannot un-choose the skeleton | Skeleton → screenshot gray-box → adjust → then skin |
| **Skin without photography** | CSS gradients, glass, fake caustics stand in for light | Plate Forge helps *awe* surfaces only; hurts dashboards | Surface-typed material policy; forbid gradient-as-hero on awe packs |
| **Component salad** | shadcn/card as the unit of thought | “Don’t be card-heavy” is a vibe | Card-count / section-type quotas in IR, mechanically scored |
| **Generic copy + fake data** | “Transform your journey” next to empty charts | Layout cannot look operational without operational objects | Bind real/synthetic Swan entities (athlete, session, PR) as first-class inputs |
| **Self-skinning the past** | Admin dashboard as gold | Audit is right (one line): parity with mediocrity | Drop dashboard-as-universal-gold; gold is the exemplar vault |
| **Viewport-last** | Design 1440, squeeze to 375 | Five screenshot sizes after the fact | Separate skeletons for 375 vs 1440, not one fluid soup |
| **Motion invisibility** | Cinematic bar is temporal; screenshots are not | Visual Director as specified cannot see the quality bar | Video capture / motion budgets later; don’t pretend stills judge cinema |
| **Open taste** | Rejections recorded, never read | Real, but it memorizes “not this slop” if you close it first | Close *after* a positive bar and structural constraints exist |

If you close taste first, the profile becomes a bag of negatives harvested from slop rounds. Negative profiles produce “not glassmorphism,” which is another road to generic.

**CONCRETE FIX.** Encode the first five mechanisms as CI-failable tests (denylist hit, card budget, gradient-hero ban, default-Tailwind type-scale ban, missing-entity bind). Do not add a VLM critic until those tests exist and a 20-page Sean-judged gold set exists. Treat “cinematic depth / crystalline atmosphere” as brand-book language, illegal in generator prompts.

## 3. Absence-first: the money is in a positive bar, a layout IR, real content, and motion — none of which the upgrade blueprint owns
**CLAIM.** A world-class design team has things neither the repo nor this plan provides. Ranked by value left on the table:

**EVIDENCE/REASONING.**
1. **Annotated exemplar vault (positive bar).** Humans design against a wall. The plan has doctrine, not 15–30 pages Sean has already ranked, with “this is the signature / this is the fail.” Without that, Elevate is undefined and 70% preference is “less ugly than slop.”
2. **Layout IR / composition step.** Humans sketch structure. The plan still lets the model emit components. Atelier’s “fingerprint against superficial variation” remains doctrine; the blueprint does not make the IR real.
3. **Domain content, not lorem.** Swan is a training OS. Density and operational clarity come from real objects and real IA (next session, load, readiness, risk). The 12-brief set still talks like a marketing-page generator. Fitness-market visual position (Whoop / Peloton / Future / Trainerize — what we are *not*) is absent.
4. **Shot language, not “hero plate.”** Cinematic look is focal length, lighting, crop, bodies, time of day — or a deliberate non-photo composition (type + data). Unconditioned image models will emit teal-glow fitness stock, which *is* the slop. No shot list, no plate QA, no “do not pretend to be a photo.”
5. **Motion as a first-class artifact.** Stated bar cannot be judged by PNG. Plan is stills-only.
6. **Typographic runtime.** Measure, optical size, tabular figures, overflow of real numbers. Doctrine mentions type; nothing typesets or QA’s type beyond contrast.
7. **Break-the-system ticket.** Art direction violates tokens. Canon-only generation guarantees brand convergence (audit §6, correct, then ignored by a Swan-shaped kernel loop).
8. **Senior human gate with SLA.** The plan tries to automate Sean. Until a critic agrees with Sean on a held-out set, Elevate is a suggestion queue, not a brain.
9. **Perf/weight budgets.** Generated cinema that blows LCP is not shippable excellence.
10. **Legal reference vault.** “Study award-winning URLs” is how you get scraped Dribbble memories or NDAs in a prompt. Need first-party, licensed, already-deconstructed references.

Classroom/printables, three domain packs, and a full Studio product are not the top of this list. They are how the money product never ships.

**CONCRETE FIX.** Before Studio, before Learning Experience, before reference-URL ingestion: check in `exemplars/swan/{win,fail}/*.png` + YAML (signature moment, skeleton id, why). Every diverge round must pairwise against one win and one fail. Ship layout IR in the same milestone as the denylist. Bind a synthetic Swan dataset as a required input for any operational brief. Defer motion QA to a later P1 with video capture, but do not claim the cinematic bar is met by screenshots.

## 4. Top-5 upgrades (build / I/O / behavioral acceptance / naive failure)

### 4.1 Layout IR + slop denylist + intra-round fingerprint (highest leverage)
**Build.** A schema, not a prompt. `LayoutIR`: viewport target, zones (x,y,w,h or grid coords), section types from a closed enum, focal point, density map, card count, material slots, motion slots, skeleton_id. Compiler to existing components. Corpus `slop-skeletons/` of banned hashes (hero-3card-cta, glass-bento, logo-cloud-then-features, etc.). Distance function on IR, not on Tailwind strings.

**I/O.** In: brief, pack constraints, optional taste features, denylist, other IRs in round. Out: ≥3 IRs + hash + distance matrix + compile receipt. No JSX until gate passes.

**Acceptance.**
- Fixture `briefs/marketing-vague.json` produces 3 IRs with pairwise distance ≥ τ (fixed in test).
- Fixture classic 3-card hero IR is always rejected.
- Adding a produced IR to the denylist causes regeneration; test fails if the same skeleton_id ships.
- `skeleton_id` of compiled DOM matches IR (round-trip), so the model cannot emit IR-A and code-B.

**Naive failure.** Hashing class strings; denylist of three patterns and the model uses equally generic #4; IR that is prose (“bold cinematic hero”); compiling by handing IR JSON back to the same LLM and asking for JSX with no schema check.

### 4.2 Mechanical inspector + receipt-gated router + Fix-apply-verify
**Build.** Extend existing Playwright (viewport sweeps, overflow, a11y, goldens). Do **not** start `visual-director/critique`. Add deterministic meters: overflow, contrast, tap targets, card-count, chrome-to-content ratio in first viewport, CTA competition, background-is-css-only, type-scale-is-default-Tailwind, section-sequence vs denylist, font-count, image-weight. Receipt is a hashed JSON the router must attach to close a UI task. Fix-lane patches are code mods with before/after screenshots and automatic revert if meters do not improve.

**I/O.** In: route, states {populated, empty, loading, error, mobile-nav}, viewports 375/768/1440 (3840 only on awe packs, sampled). Out: receipt, patch set, before/after, unfixed list.

**Acceptance.**
- Page with 6 first-viewport cards fails pack `max_cards_fold=3`.
- Awe-pack gradient-only hero fails `material_slot_filled`.
- 375 overflow fails; auto-fix either clears it or receipt marks `unfixed:overflow` and the workflow cannot claim “done.”
- Deleting the receipt file fails CI even if screenshots exist.
- Canary PII string in populated state never appears in any outbound payload (see F8).

**Naive failure.** Thresholds that always pass; receipt written but router not checking (ledger 2.0); auto-apply thrashing spacing vs density; calling this agent “Visual Director” and stuffing a VLM behind it on day one.

### 4.3 Exemplar vault + pairwise gate (defines “good”)
**Build.** 15–30 Sean-labeled pages (win/fail/borderline) with skeleton_id, signature crop, notes. Diverge round must render first-viewport of each direction and run forced-choice vs one win and one fail (human or, later, a scorer trained on Sean’s picks). No Elevate prose without a pairwise.

**I/O.** In: candidate first-viewport PNG, vault ids. Out: preference bits, distance-to-win skeleton, “too close to fail-template” flag.

**Acceptance.**
- A known fail-template fixture loses to the vault win in 10/10 automated skeleton checks.
- Sean’s held-out 10 pairs: system’s recommended direction matches Sean ≥7/10 *after* calibration; until then the gate is “Sean picks,” not “ship.”
- Removing the vault fails CI for awe and marketing briefs.

**Naive failure.** Vault of 3 dribbble-likes nobody ranked; CLIP similarity to “cinematic” (another fake score); using the admin dashboard as a win; pairwise on full-page 3840 screenshots nobody looks at.

### 4.4 Surface-typed materials on the *existing* Forge, not a parallel Plate Forge
**Build.** Pack field `material_strategy`: `awe_photo | type_data | print_none`. Awe: select IR *first* (gray-box), then Forge generates plates that match focal geometry; all crops reference pack IDs; CSS-gradient cannot fill a material slot. Operational: synthetic Swan entities only; cinematic hero plate is a pack-policy fail. Print/classroom (if ever): ink/contrast, no Forge. Extend Forge in place (brackets, contact sheets, winners, lineage, spend already exist). Kill any new `plate-forge/` directory.

**I/O.** In: IR + strategy + budget. Out: pack (hero/env/detail/proof/crops) + QA + spend + lineage. Layouts consume IDs.

**Acceptance.**
- Two different IRs cannot ship the same hero crop id.
- Operational brief that includes a generated cinematic plate fails pack policy.
- Awe brief with empty material slots fails.
- Spend receipt ≤ budget; lineage points at Forge run id.
- Unplugging Forge fails awe CI, not dashboard CI.

**Naive failure.** Generate a shared pack *before* IR so every direction is the same poster with different padding (the audit’s “same pack so user judges structure” *forces* this). Un-QAed teal-glow bodies. New folder nobody calls. Applying Plate Forge to teacher printables and operator cockpits.

Chicken-egg is real: materials-before-layout is right for a *chosen* cinematic direction, wrong as a universal kernel stage. Co-evolve: IR thumbnail → plates → layout, or 3 IR worlds → 3 plate worlds. Never 1 plate world → 3 skins.

### 4.5 Taste consumer at IR/render layer, hard-isolated
**Build.** Reader for the existing append-only ledger; quarantine unknown/placeholder reasons; distill versioned profile of *features* (allowed skeleton families, density, type step, motion, material warmth) with provenance + confidence. Inject into IR generation, not adjective soup. Storage: `taste/swan/`, `taste/lxs/` separate trees. Session loads one namespace. No concatenation.

**I/O.** In: ledger events (reason enum required or explicit skip). Out: `profile.vN.json`. Next IR set.

**Acceptance.**
- Flip `prefer_split_editorial_hero=true` in Swan profile → next Swan IR set includes that family and hashes change; screenshot first-viewport changes (pixel or skeleton delta, not markdown delta).
- Classroom `pastel_print=true` is string-absent from Swan prompt assembly and does not change Swan hashes (cross-read test must fail the build if it succeeds).
- Unknown reasons cannot appear as hardened features (unit fixture).
- Brief-only diff with identical IR hashes fails the test.

**Naive failure.** Dump JSON into the system prompt; negative-only features; testing `pre-brief.md` text; one `taste.profile.json` at repo root (the audit’s own ghost file) shared across packs.

## 5. Architecture: kernel + packs is the right *idea* and the wrong *launch split*
**CLAIM.** Shared kernel / domain packs is correct. Three packs (Swan / general web / Learning Experience) as a near-term plan is scope suicide. The audit’s single kernel loop `DISCOVER → DIVERGE → CREATE MATERIALS → RENDER → INSPECT → CRITIQUE → REVISE → VERIFY → LEARN` is a cinematic-web loop pretending to be universal. Printables and operator dashboards will be damaged by it. Taste isolation described as a JSON hierarchy will leak via prompt stuffing.

**EVIDENCE/REASONING.** Kernel loop mandates CREATE MATERIALS before layout for classroom worksheets and for a trainer cockpit. That is how you get illustrated-animal heroes on lesson plans and cinematic plates on tables of session data. “General Web/Brand Studio” is a second product Sean did not ask to ship. Classroom briefs in the launch benchmark (audit’s 12) couple the money product’s gate to a family tool.

Hierarchy `user → domain → project → artifact-type` is a memory *model*, not an isolation *mechanism*. One process that reads both profiles will paste both into context “for completeness.” That is contamination.

**CONCRETE FIX — contract.**

Kernel **may** own: session/ledger engine (keyed by pack), IR schema + compiler interface, mechanical capture/meters, receipt state machine, N-up compare, profile distillation *engine*, cost ledger, redaction, Forge adapter.

Kernel **must not** own: Swan tokens, crystalline grammar, “hero plate” as a required stage, viewport 3840, motion language, copy voice.

Pack **must** provide: exemplar vault, forbidden skeletons, token set + break-glass exceptions, `material_strategy`, content bindings, viewport policy, motion policy, autonomy matrix, taste namespace path, pack-specific critique catalog (not “is the hero timid?”).

**Isolation:** one pack loaded per session; taste files on separate paths; CI poison-test (see 4.5); no shared prompt buffer. Classroom is a pack *schema* and a contamination test, not a launch deliverable. Do not build General Web until Swan awe + Swan operational both pass their own gates.

Autonomy matrix the audit left as vibes (needed because “builder makes zero decisions” is a real conflict — agreed, one line):

| Class | Examples | Authority |
|---|---|---|
| Objective | overflow, contrast, hit target, missing state, a11y | auto-apply + verify + revert |
| Craft | one type step, spacing rhythm, density within budget | auto-apply with screenshot proof, cap N diffs |
| Direction | skeleton, imagery, color world, motion, signature | render alternatives, human pick |
| Identity | tokens, voice, IA, pack grammar | never without human |

Implement as a privileged polisher role with a diff budget, not as “the builder woke up.”

## 6. Visual Director: keep the lanes, kill the omniscient VLM, split mechanical vs residual
**CLAIM.** Keep/Fix/Elevate/Wildcard is a decent *product* shape. The specified implementation will be expensive, leak PII, miss motion, and emit confident wrong prose. Five viewports including 2560 and 3840 on every route, plus populated/empty/loading/error/mobile-nav, plus DOM plus computed styles, is a cost and context bomb. “Safe-to-auto-apply” from an LLM will be mislabeled. Obligatory Wildcard every pass trains humans to ignore it.

**EVIDENCE/REASONING.** LLM screenshot critique fails in known ways: invented clipping, missed hierarchy, praise for glow, inability to judge type measure, blindness to animation, self-preference. Full-page 3840 is unread by both human and model; first-viewport + crops are what art directors actually use. Objective issues (the Fix lane) are already mostly measurable with the Playwright infra that exists. Putting them behind a VLM is a downgrade in reliability.

**CONCRETE FIX.**
- **Keep:** lanes; evidence crop + selector; no single beauty score; human pick for direction; null-winner (agreed, one line).
- **Delete:** mandatory 2560/3840 every run; mandatory Wildcard on polish passes; VLM-authored `safe-to-auto-apply`; folder fantasy `analyze-layout/critique/build-revision-brief/...` as P0.
- **Split:** Mechanical Inspector = Fix (deterministic). Art Director = Elevate residual only, different model family from the generator, first-viewport + ≤3 crops, forced choice from a *pack move catalog* (recompose fold, type relation, signature moment, density, sequence) — not free essay. Wildcard only on diverge rounds, as a rendered alternative, not a paragraph.
- **Reliability protocol (this is how you make a VLM critic non-theater):**
  1. Gold set of 20 pages with Sean’s Fix/Elevate labels.
  2. Director may not emit a finding without crop coords; schema-drop otherwise.
  3. Fix-lane precision ≥90% vs gold (false-positive Fix is poison because of auto-apply).
  4. Elevate: Sean prefers rendered alternative ≥60% pairwise on held-out, or it stays advisory.
  5. Log generator-vs-director disagreement; never let generator critique itself.
  6. Mechanical meters run first; VLM only sees residuals.
  7. Populated screenshots never leave the box (redact / synthetic data). Canary PII test.
- **Add:** motion later as video strips, not as a stills pretender. Cost cap per round. Revert.

Do not “elevate” the Director until 4.2 and 4.3 exist. Otherwise you have built Atelier-ledger-but-for-opinions.

## 7. The 12-brief / ≥70% blind preference gate will certify slightly-less-slop and three products at once
**CLAIM.** Wrong mix, wrong judge, wrong statistic, wrong “vs current.” Beating a 1.5/5 system 70% of the time is how you launch slop with a ribbon. n=12 cannot support that percentage. Mixing classroom printables with cinematic marketing measures the compromise kernel.

**EVIDENCE/REASONING.** Preference without *who* is noise: Sean ≠ target trainers ≠ other designers. “Genuinely different structures” is already better measured by IR distance (4.1) than by a human squinting at 12 pages. Operational pages need task success (find next session, log a set), not beauty preference. Cost, latency, and “looks like AI in 3 seconds” are absent. Null-winner is in the gate list and should stay.

**CONCRETE FIX — split gates, ship Swan first.**

**Swan marketing/awe (n≥8, Sean + 1 other designer):**
- IR pairwise distance ≥ τ; 0 denylist hits.
- Material slots filled; no gradient-as-hero.
- First-viewport signature exists (non-card anchor).
- 3-second “is this a template?” protocol: ≤2/8 judged “obvious AI template” by the designer rater.
- Sean pairwise vs current ≥8/8 to *replace* current, not 70%. If you must keep a percentage, use it on a held-out customer panel as a *secondary* metric, n≥30, after Sean-gate.

**Swan operational (n≥6, trainer task scripts):**
- Task success ≥ current, time-on-task not worse.
- Synthetic data bound; zero decorative plates.
- a11y and overflow receipts green at 375/1440.

**System tests (CI, every PR):**
- Receipt present; taste cross-read fails; canary PII absent; spend ≤ budget; doctrine-adjective linter on generator prompts.

**Not in v1 gate:** classroom deck, printable, teacher planner, “general web,” vague-brief-as-half-the-set. Keep one intentionally vague *Swan* brief to test diverge, not to dilute the pack.

Drop ≥70% as launch law. It is a number that wants to be gamed by prettier palettes.

## 8. Hardening: the plan will regress to doctrine via cost, PII, auto-apply, and unenforceable words
**CLAIM.** Failure modes are predictable and already have a repo pattern (claimed mechanism never built; two skill surfaces; writer without reader). If receipts, budgets, isolation, and “adjectives are not code” are not tests, the Visual Director and taste profile will become more unread canon.

**EVIDENCE/REASONING.**
- **Cost:** 5 viewports × 5 states × N routes × VLM + Forge brackets × 3–5 directions × revise rounds. Someone will stub the Director to markdown to save money. That is the regression path.
- **PII:** populated trainer dashboards into external VLMs is client data exfil. Audit’s “privacy-safe references” does not cover this. Remit requires zero client PII to external models.
- **Auto-apply:** VLM-tagged “safe” spacing/contrast patches will break density and RTL/edge states. No revert = silent production damage.
- **Determinism:** image gen + LLM critique without pinned models/seeds/fixtures cannot replay a failure. Forge already tracks lineage; the plan does not require replay.
- **Drift:** doctrine corpus vs runtime. Canon checker still missing. If a rule is not a test, it is literature.
- **Prompt injection:** Studio annotations and fetched reference URLs become instructions.
- **Taste poisoning:** unknown reasons, one loud session, classroom pastels in Swan context.
- **Routing fragmentation:** new skill that is not advertised never fires (audit is right; one line). “One canonical workflow YAML generating mirrors” can itself become unread unless `build` proves advertised==exists==called.

**CONCRETE FIX.**
- **Receipt or it didn’t happen.** Workflow cannot close without hashed receipt: IRs, meters, patches, spend, pack id, taste namespace. CI greps for UI PRs missing receipts.
- **Cost governor.** Hard $ and token cap per round; degrade by dropping VLM and extra viewports first, never dropping mechanical meters or denylist. Persist spend next to Forge’s existing tracker.
- **Privacy.** Design runs use synthetic fixtures only. Redact before any external call. Canary strings (`SSN_CANARY_9182`, client display names) in populated states; test fails if they appear in HTTP mock logs. Default: local/mechanical only; VLM on first-viewport crops of synthetic data.
- **Determinism.** Pin model ids; store seeds; fixture replay of IR→compile→meters. Image packs addressed by lineage id, not “latest.”
- **Doctrine linter.** Runtime prompts may not contain the adjective list (cinematic, crystalline, awe, …). Enforceable rules live only as tests/meters/denylist/exemplars. Unenforceable text lives in a human-only brand book. If the canon claims a checker, the checker must exist or the claim must be deleted in the same PR.
- **Auto-apply.** Mechanical Fix only; before/after meters must improve or revert; cap diffs; never VLM-safe.
- **Taste.** Reason enum required; quarantine; decay; one namespace per session; poison-test in CI.
- **References.** No live URL fetch to external models in v1. First-party vault only. If URL ingest comes later: fetch to disk, strip scripts, human-approve, extract through schema, never raw HTML in prompts.
- **Stop prose regression.** A stage whose output is markdown without a PNG/IR/receipt is a failing test, not a “handoff.”

Do not build the audit’s three P0s as specified. Build 4.1–4.5. Treat the Visual Director essay as a later residual critic with a calibration bar, not as the brain.
