The code's own round-8 rationale — "a shell does NOT treat them as an argument separator" — is violated by three members of its own allowlist. Failure scenario: registered command `"node ./a\u000Bb.mjs"` with on-disk file literally named `a\u000Bb.mjs` (legal on Linux/macOS). The shell passes **one** argument; node runs it — healthy. The classifier splits into `node`, `./a`, `b.mjs`; sole candidate `b.mjs`; `statSync` ENOENT → **MISSING — phantom alarm in the loud path**. Mid-token `\r` has the identical shape. The fix is a one-character-class change: allow only ` \t\n` (trailing `\r` is already consumed by `cmd.trim()`), i.e. `/[^\S \t\n]/`.
