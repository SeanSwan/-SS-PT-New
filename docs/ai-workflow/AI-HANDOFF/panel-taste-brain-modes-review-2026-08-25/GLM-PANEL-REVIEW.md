The bundle regex in `export-bundle.mjs` protects bundles only, not briefs.

(b) `profileOf(e)`/`projectOf(e)` defaults when fields are omitted are unspecified — if omitted `profileId` defaults to `'sean'`, an event with both `profileId` and `source` omitted lands silently in `sean/default`; verify with a unit test on omitted fields. Caller-field vs memory drift, build it into P1's contract now. (c) The inlined `probe.js` is a second copy by construction; drift is a when, not an if.

- **Direction (§4):** (i) **P1 is structurally empty for partner and client.** The shareable pool is Unsplash + Webb photos (§1) — real photographs carry *no Midjourney sref provenance*. "Evidence-tier srefs weighted by closest−miss margin" computes over an empty set for 2 of 3 profiles; only `sean` (Midlibrary mix) generates sref evidence.
