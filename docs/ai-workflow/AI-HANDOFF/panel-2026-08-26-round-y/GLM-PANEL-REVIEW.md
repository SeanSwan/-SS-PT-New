Absent-miss: synchronous. Expired-miss: synchronous (the plain-object fix). **Rejection-miss: behind `await pending` in `resolveReplay`'s catch — structurally impossible to make synchronous.** Failure scenario: claim `P1` at key K rejects (startLocalBatch throws before `settle.res`, or the claim wrapper rejects). `P1` sits in the store until a retry resolves it. The fix is a **get-or-set claim**: after any await, `const existing = store.get(key); if (existing !== undefined) coalesce; else store.set(key, pending)` — one sync operation, first resumer wins, second coalesces. 2. **P2 — `(snap.finishedAt || Date.now()) + BATCH_TTL_MS` uses the raw wall clock.** Every other clock read in these files goes through `clock` (`judge` samples `clock()`; the prune loop calls `clock ? clock() : undefined`; composeReplay's header essay is literally about which quantities want to be frozen). ## RECOMMENDATIONS
1. **Get-or-set claim helper, one place, both miss paths.** `claim(key, makePending)` that synchronally returns the existing entry if present. Kills Blocker 1's class permanently and lets the sync-miss invariant be enforced *by construction* instead of by comment.
2. **Make the claim/stub encoding explicit instead of duck-typed.** The whole system branches on `typeof held.then === 'function'`. Any future writer that stores a thenable (a "safe" `slimForReplay` returning `Promise.resolve(x)`) silently re-breaks the sync-expired-miss fix — two post-TTL retries, both async nulls, both render. A stub field named `then` misroutes to `resolveReplay` *and* is skipped by the prune identity check. Wrap claims as `{ claim: promise }` or tag stubs `__settled: true`, and assert on write.
3. **Shape-parity test**: replayed-during-flight body vs. replayed-after-completion body compared field-by-field — the drift guard for the three-shapes problem in ATTACKS.
4. **Red-test harness for `chargedUsd` before a paid async lane exists**: a fake `unitUsd > 0` merged now, so the parity expression the author admits "no test can redden on" has a harness waiting. The author is right that a green test can't prove it — so build the test that *can* go red.
5. **Metrics over console.error**: counters on each replay outcome (coalesced / fresh-replay / expired-refusal / rejection-clear / duplicate-claim-detected). Blocker 1's race would be *visible* as duplicate-renders-per-key; today it is invisible.
6. **Strip `key` from client-facing bodies** in `slimForReplay` — the internal scoping scheme is not contract, by the same reasoning the module already applies to `replayExpiresAt`.
7. **SWA-165** (global client-keyed eviction): before any paying async lane ships, bound `settledKeys` per-user — the filed-not-gated status is fine for a free local lane only.
8. **Fail loudly on a terminal row without `finishedAt`** rather than the `Date.now()` fallback — a missing `finishedAt` at `.finally`-time is itself a defect worth a telemetry line, not a silent re-anchor.
