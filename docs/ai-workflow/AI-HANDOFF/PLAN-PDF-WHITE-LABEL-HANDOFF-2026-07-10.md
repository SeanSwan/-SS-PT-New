## 1. The mission (what & why)
- **Two-part branding model** (Sean's decision, do NOT co-brand): `move_fitness` client → **full white-label to Move Fitness** (nothing SwanStudios anywhere the client can see, including the saved filename). `swanstudios` client → SwanStudios branding, with an **optional** discreet "in partnership with Move Fitness" cross-promo (opt-in, off by default). `external`/unknown → SwanStudios (fail-safe).

- **Delivery Sean asked for:** auto-correct branding by client type + a real-PDF preview + 1-tap "Approve & Download", with a secondary "Customize header" editor (logos, wording) whose changes SAVE as reusable per-brand presets.

A failed frontend build keeps the last good bundle (site won't break). Stage EXPLICIT paths, never `git add -A` (other agents share the tree — Rule 67).
- **Local test infra:** a fresh worktree has no `node_modules` (gitignored). Junction the primary tree's deps: PowerShell `New-Item -ItemType Junction -Path <worktree>/frontend/node_modules -Target <primary>/frontend/node_modules`. Caveat: those deps are from the (possibly stale) primary tree → a `tsc`/build error for a module NOT in the junctioned deps (e.g. `@zxing/browser`) is a FALSE positive if the module IS in current-main `package.json` (Render installs fresh). Verify with `grep <pkg> package.json`.
- **`tsc` needs a big heap:** `NODE_OPTIONS=--max-old-space-size=8192 npx tsc --noEmit` (default heap OOM-crashes at exit 134). Filter errors to your changed files; disclose baseline non-cleanliness (Rule 56).
