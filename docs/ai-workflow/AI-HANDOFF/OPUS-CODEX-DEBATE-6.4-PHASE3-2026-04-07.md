### Modified Backend File (1)

#### 1. `backend/routes/adminSocialPublishingRoutes.mjs`
3 new endpoints added (all behind existing protect + adminOnly middleware):

- **GET /calendar-suggestions** — Returns 7-day content plan with day-of-week themes:
  - Sunday=Motivation Monday Prep, Monday=Motivation Monday, Tuesday=Technique Tuesday, Wednesday=Wellness Wednesday, Thursday=Throwback Thursday, Friday=Fitness Friday, Saturday=Saturday Spotlight
  - Each day: date, theme, suggestedContent, category, bestTime, hashtags
  - Hashtags auto-generated by category (motivation, education, wellness, social_proof, engagement, community)

- **GET /best-times** — Returns optimal posting times per platform (Instagram, Facebook, YouTube, TikTok, BlueSky):
  - Per-day time slots based on fitness industry engagement data (Sprout Social + Hootsuite research)
  - peakDay + peakTime per platform
  - Platform-specific notes explaining why those times work

- **GET /auto-post-templates** — Returns 6 pre-built templates with live community stats:
  - Queries User.count(), Gamification.findAll() for real totalWorkouts, totalXP, longestStreak
  - Templates: Weekly Recap, Milestone Celebration, Daily Motivation, Training Tip, Challenge Invite, Feature Announcement
  - Each has frequency tag (daily/weekly/milestone/as_needed)
  - DB queries are best-effort — templates render with zeros if DB unavailable

- **Helper: getHashtags(category)** — Returns category-specific hashtag strings, all include #SwanStudios base

### New Frontend File (1)

#### 2. `frontend/src/components/DashBoard/workspaces/marketing/ContentCalendarPanel.tsx`
- 3-tab sub-navigation: "7-Day Calendar" | "Best Times" | "Auto-Post Templates"
- **Calendar tab:** 7-column responsive grid (3-col on tablet, 1-col on mobile). Each day card shows: day name, date, theme badge, suggested content, best post time. Today highlighted with accent border.
- **Best Times tab:** Per-platform rows showing all optimal times per day. Peak day/time highlighted in gold badge. Platform notes below.
- **Times rendered as `TimeSlot` chips** in Fira Code monospace.
- **Templates tab:** Card per template with name, frequency badge, pre-formatted content in code block, "Copy to Clipboard" button with 2s "Copied!" feedback.
- Fetches all 3 endpoints in parallel on mount via Promise.all.
- Uses shared MarketingCard, CardHeader, HeaderLeft, IconWrap from marketing.styles.
