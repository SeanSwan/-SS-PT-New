**Ranked findings (cost × likelihood)**

1. **lane-core.mjs `parseLane` (~lines 170-176, the `.flatMap` block)** — Splits each line on `[,\s]+` *before* `clean` strips quotes, so a quoted path with spaces (`"backend/migrations/014 add col.sql"`) breaks into `backend/migrations/014`, `add`, `col.sql"`. Only the first token survives as a lock. Directly defeats the round-4 `core.quotePath=false` fix (push-blast-radius.mjs) and produces wrong/missing locks for exactly the migration case called out. High cost, high likelihood.

2. **tree-sentinel.mjs:133 (+125-138)** — Calls `parseLane` directly and never applies the round-4 idle guard (`readLanes` in lane-core.mjs ~line 210 zeroes locks when `Status: idle|released|done`). Sentinel reports phantom locks for idle lanes; push hook (via `readLanes`) does not. Reader/reader disagreement. High likelihood, medium cost.

3. **push-blast-radius.mjs `dashC` regex (~line 66) and the git-detection regex (~line 60)** — `REPO` is set only from `-C ` (space-required) and ignores `--git-dir`/`--work-tree` even though the new detection regex explicitly admits them. `git --git-dir=/x push` or `git -C/path push` analyses `process.cwd()`, printing wrong branch/diff/deploy verdict with no disclosure. High cost, medium likelihood.

4. **lane.mjs `release()` (diff hunk ~149-165)** — Loop counts any non-empty line as removable and `splice` replaces the entire span with `- (released)`. A lower-level heading (`### backend`) is not a terminator, so sub-headings/notes inside the section are deleted. Writer destroys structure the reader tolerated. Medium cost, medium likelihood.

5. **lane-session-start.mjs:35** — Prints `node scripts/lane.mjs claim …` as a *relative* path. The hook itself resolved `LANE` from `__dirname`, but the advertised command fails with ENOENT if the agent runs it from a subdirectory (the exact bug the hook was written to fix). Claim believed, not executed. Medium cost, medium likelihood.

6. **lane-core.mjs `lockMatches` (~lines 230-240)** — Bare `*` (or any pattern without `**` or trailing `/`) yields empty `body` and `subtree=false`, so regex `^$` matches nothing. Previously `*` matched files (with the old `(?:/.*)?`). Narrowing is unintended for a single `*`. Low cost, low-medium likelihood.

7. **lane-session-start.mjs:33** — `if (out)` suppresses all output when `lane.mjs digest` returns empty; the hook then exits 0 silently, contradicting its own “never fail-silent” mandate. Low cost, low likelihood.

8. **tree-sentinel.mjs:126** — `agent` is set to the full `.lane.md` stem (now includes slug + session suffix), not the agent name; any `--json` consumer expecting agent identity gets a malformed key. Cosmetic, low cost.
