   15-design failure mode (present late, build early). Kimi: "three independent ways to lose
   weeks." Qwen: "STOP Slice A." Grok: "REJECT."
2. **LCP/SEO on a video-first hero is a P0 nobody had planned.** Poster frame as real
   `<img fetchpriority="high">` under the canvas; headline as real HTML text, never baked into
   canvas/video; video/frames lazy-hydrated after LCP; budget LCP ≤2.5s at 375px/4G.
3. **The shared unpushed branch (25+ commits, two live agents) is a merge bomb.** Push now;
   short-lived feature branches off main for product code; mediasync delivers *artifacts*
   (frames/master) to an assets path, never code edits on the shared branch.
4. **Canvas frame-scrub beats `video.currentTime`.** Committed, not open: extracted frames on
   canvas, chunk-lazy-loaded, IntersectionObserver-gated; `currentTime` rejected (mobile-Safari
   seek jank, decoder stalls). Kill-switch budget: total frame payload ≤6MB, jank ≤8ms/frame at
   375px, else static poster hero ships and scrub waits for Slice C.
5. **Analytics baseline before the rebuild ships.** CTA events, scroll-depth per section,
   flag-variant tagging — baselined on V4 first or the A/B result is meaningless.
6. **The fee copy now points nowhere** (stripped numbers = dangling pricing intent). A `/pricing`
   stub or honest consult-path block is a Slice-0/A item, not polish.
7. **Rollback = server/env-driven flag, default OFF, verified by a smoke test; teardown path
   documented.**
