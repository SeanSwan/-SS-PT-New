## 1. What was broken

The studio was asked to serve the **other websites Sean builds**, not only SwanStudios. `workspaceId` was already accepted by every endpoint and threaded through every service — and used for exactly one thing: a free-text tag on the asset row, `workspace:whatever-you-typed`. Nothing validated it. **Nothing read it.** So a render for another site was judged by SwanStudios' brand laws and dressed in SwanStudios' palette.

A workspace that changes nothing about the output is a label, not a workspace.

**Two kits ship.** `swanstudios` (lawProfile `full`, 3 style anchors, 5 palette words) and `universal` (lawProfile `universal`, nothing appended). **Sean's other sites are deliberately NOT invented here** — a brand kit is a claim about how someone's brand looks, and guessing one would put fabricated art direction in front of a model with his name on the output. Adding a real kit is one object plus his answers.

### The design error the existing tests caught

My first draft made **`workspaceId`** select the kit. The suite refused instantly: callers already pass ids like `ws-1` as a *filing* label, and there is no art direction by that name. I had merged two concepts.

They are now two fields. **A brand kit is art direction** — small, curated, reviewed like code, therefore a strict allowlist where an unknown id **refuses** (`E_UNKNOWN_BRAND_KIT`, 400) rather than falling back. **A workspace id is a filing label** — free text, unchanged. Demanding that every label be pre-declared in source would make filing an asset a code change.

### Two things I got wrong and fixed before this packet

- **The kit's own words were refused by the brand's own law.** I listed `"gilded fern gold used sparingly"` — true of the CSS palette — and every brief was rejected by LAW2, the gold allowlist. The law was right: gold is permitted in four UI places, none of which is a subject in a generated image. **A palette entry that exists for CSS is not automatically art direction.** Pinned by a test.
- **A dormant `negative` field.** The kit carried one; nothing consumed it. Worse, wiring it naively would have bypassed an existing gate — `swanPromptCompiler` owns the negative slot and only emits it when a provider's `honorsNegativePrompt` capability is `'verified'`, precisely so a provider that merely *claims* support cannot drop it silently. Removed rather than shipped inert.

## 3. Open questions — please attack these

1. **The taste path does not get the kit.** `applyBrandKit` runs only on the brief path (`composeStills.mjs:206`). Taste prompts come from Sean's rated corpus, which already *is* his taste — so layering Swan's anchors on top would double-dress. But for a **non-Swan site**, taste prompts still carry Swan taste and nothing says so. Is the right answer (a) leave it, (b) apply the kit to taste output too, (c) refuse `taste` + a non-default kit outright, or (d) something else?
2. **Is a module the right home, or is this a table in disguise?** I argued a kit is a decision reviewed like code, not user data, and that a table means a migration and a CRUD surface for something that changes a few times a year. The trigger I named for revisiting is "kits become per-tenant and user-editable." Is that trigger in the right place?
3. **`lawProfile` override.** An explicit request `lawProfile` beats the kit's, and the result records `lawProfileOverridden: true`. Is a recorded override enough, or should overriding a kit's laws require something stronger — given the laws exist to protect the brand from exactly this?
4. **Prompt-order claim.** `applyBrandKit` puts the operator's words first and the brand language after, on the reasoning that diffusion models weight the front of a prompt and the reverse reads as the brand describing a subject. That is a claim about model behaviour I have **not** measured. Is it right?
5. **What is missing?** Per-kit aspect enforcement, per-kit spend budgets, a kit on the Motion rung (video currently gets none), showing which kit rendered an asset in the library, and non-visual brand facts (voice, forbidden words). Rank them, and say what you would cut.
6. **Gaps and context I may be missing** — anything about this that looks wrong from outside it.
