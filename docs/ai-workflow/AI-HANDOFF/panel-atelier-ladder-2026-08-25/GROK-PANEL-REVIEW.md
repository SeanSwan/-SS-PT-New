## VERDICT

## BLOCKERS
1. **P0 — Publish snippet is not a publishable asset.** Operator calls `POST /asset/:id/status` → `published`, then `GET /asset/:id/reference` and pastes the returned `<img src="…signed…">` into a Swan (or other) site. Default 4h expiry → every production page 404s/403s after lunch. Unpublish cannot retract a URL already copied; there is no CDN/public key in the packet. Evidence: §2.1 Publish rung (`publishAsset`, “read URL + `<img>/<video>` snippet … withheld until published”); §3 Q2 (“expires (4h default)”).

2. **P0 — Commercial-safety gates are dead code, so H3 can ship.** Persist writes `consentConfirmed:false` and never sets a required/grant/attribution flag. Publish “refuses by the FROZEN provenance” only if those bits are on. Input: Motion (or a future local lane) runs MiniMax H3 from `Z:` with no grant; `POST /asset/:id/status` → `published`. Output: commercially-unsafe asset is live; the gate “never trips.” Opposite reading (refuse unless `consentConfirmed`) would block *all* publishes — also a ship-stopper. Evidence: §2.2 “nothing in the pipeline sets a flag yet, so today the consent gate never trips”; §2.1 Publish refusal list; §2.2 “H3 non-commercial until grant.”

3. **P0 — Motion bind will fail first at download, and `permanent:true` strands the asset.** Queue stores `initImage` as an OBJECT; agent later downloads, re-hashes, uploads to ComfyUI. If that object carries a signed URL minted at enqueue (the only read-URL contract in this packet), any queue wait > TTL → hash/download fail. Half-fail: bytes land in ComfyUI input, graph/job dies → disk leak, no GC. Hash mismatch marked `permanent:true` then permanently kills a legitimate re-persist (month-rolled key, R2 overwrite, or agent fetched a transformed body). Evidence: §2.1 Motion (`motionBind`, `handlers/initImageBind`, “re-hashes at the point of use”); §3 Q1; persist key “sha256 per owner per month.”

4. **P1 — `/stills` is a multi-minute sync HTTP request on a single-flight in-process lock.** 4-up × ~27s/frame ≈ 2 min inside one `POST /stills`, VRAM admitted once at start. Browser/proxy/Node timeouts cut the socket; operator sees a hung Generate; GPU keeps going; persist may never run (“never hides a still” cannot hold if the client is gone). Concurrent MCP `free_memory`/`stop_comfyui` (no consent gate) mid-batch → OOM/kill, no job to resume. Evidence: §2.1 Still; §2.2 MCP “`stop_comfyui`/`free_memory` reach no consent gate”; §3 Q3; §2.2 “nothing proven against a real ComfyUI.”

5. **P1 — Free Still rung has no honest working path on the box.** Weights: Wan 2.2 TI2V-5B + H3; “No image checkpoint”; Wan stills “unprobed”; hosted refused until `SWAN_ATELIER_MAX_SPEND_USD_DAILY>0`; local refused until `SWAN_ATELIER_LOCAL_STILLS=probed`. After merge the Generate control is gold/`claimed` with no free fallback. SWA-207 (FLUX.1-schnell) is not on the listed disk image, so the probe protocol itself is not runnable. Evidence: §2.2 Weights / probe; §2.1 Still lane flags.

6. **P1 — Asset identity is not the sha256 the bind checks.** Persist: “key = sha256” *and* “Key = sha256 per owner per month.” Same bytes in October and November → two R2 objects, two `MediaAsset` rows (or one row pointing at the wrong month). Second site → library/IDOR/query bleed, not a clean FK miss. Evidence: §2.1 persist; §2.2 “Workspaces do not exist; `workspaceId` rides in `tags`; `MediaAsset.projectId` … left null”; §3 Q4.

## ATTACKS
- Correctness: Happy path only — 195+ backend tests inject fakes; bind/persist/VRAM/Comfy never run on the 5090. `/stills` has no job contract, so timeout/retry is undefined (double generate vs silent GPU orphan). Motion idempotency is “asset+hash+prompt+minute” → client retry at :59/:00 enqueues two video jobs. Single-flight is process-local: nodemon/crash/second Node = two admissions. VRAM sampled once: a video job or MCP free mid 4-up invalidates the admission. Partial 4-up failure vs “never hides a still” is unspecified. `consentConfirmed:false` start state vs “gate never trips” means the real predicate is almost certainly `if (flag) refuse` with flags never written — tests can be green while the safety model is inverted. Prompt law-filter ≠ pixel filter: a loopback-legal prompt can still paint a likeness; Publish will not see it. Unpublish is cosmetic against already-issued signed URLs. Color-only gold lane strip is a WCAG 1.4.1 miss even if contrast hits 4.5:1; Dual-Button Glow / 44px / dark-first / token fallbacks are asserted as constraints, not shown.

- Security: `GET /asset/:id` returns “owner-scoped record + provenance + read URL” while Publish “withholds” the read URL until published — if “owner” is the single admin session, every draft of every future site is one IDOR/guessable-id away; if `/asset/:id` is reachable with a stolen cookie, draft signed URLs leak. `POST /asset/:id/status` state machine (no jumps) has no documented authz/CSRF story. MCP 39 tools, allow-list is a *doc*: any local process can `stop_comfyui` / `free_memory` and hijack the 5090 (availability + GPU tenancy). Agent download of `initImage` is SSRF-shaped if the object URL is not forced back to the owner’s R2 key. Hosted OpenRouter stills (when the spend key is flipped) send full prompts, not IDs — violates zero-PII-to-LLMs the moment Sean pastes a client name. Taste brain is “loopback-pinned, GET-only” — pin must be in the client allowlist (host + no redirects + no `X-Forwarded-*` trust), not a comment. No spend ledger + reserve-at-start: two tabs can each pass `/estimate` and `/stills` under a per-batch ceiling; `/limits` already admits the daily ceiling is a lie. Rate-limit/DoS: one `/stills` holds the GPU ~2 min; Comfy input dir grows on half-failed binds; no per-tool MCP disable.

- Data-truth / schema drift: R2 key template disagrees with itself (`sha256` vs `owner/yyyy-mm/sha256`) and with Motion’s “recorded hash” identity. `MediaAsset.projectId` (content_projects FK, null) vs `workspaceId` in free-form `tags` — two sources of tenancy, neither written by Compose. Frozen `buildProvenance` vs live grant/territory at publish: a later H3 grant cannot unblock a frozen “no grant”; a missing territory bit cannot be added without rewriting history. `initImage` OBJECT on the video queue vs Comfy graph filename — two shapes, one undocumented mapper. Frontend `/limits` + lane strip + Publish panel must match tri-state `claimed|probed|refused` and the real withhold rule; packet never shows the response JSON. `lawProfile: full|universal` only — §1 says this studio also feeds *other* Sean sites; LAW10 / “26+ years / NASM-protocol” / stretching-not-yoga will rewrite non-fitness prompts. PascalCase `MediaAsset` vs whatever the PG columns are is unverified; if persist writes camelCase into snake_case columns, provenance flags are silently dropped — which would exactly produce “gate never trips.”

## HIGHEST RISK
Publish as specified will put expiring, un-revokable signed URLs on real websites *and* will not stop a grant-required H3 run — that is how this studio injures Sean the first week he trusts it. Cheapest de-risk before merge: (1) make `GET /asset/:id/reference` return a stable app path (or public R2/custom-domain key) that re-resolves/re-signs server-side; use 4h signed URLs only for draft preview; (2) at persist, write the licence snapshot from model-id → `{consentRequired, grantRequired, attribution}` in `buildProvenance` (H3 → grantRequired=true) and unit-test `publishAsset` against that row, not against a comment. Do not flip `SWAN_ATELIER_LOCAL_STILLS=probed` until SWA-207 has actually produced a still on this box.
