## Promotion rule

Promotion is a normal reviewed code change: move the chosen implementation import from `frontend/src/pages/DesignPlayground/playgroundRegistry.ts` to the canonical route seam, satisfy the full design/data/auth/responsive review chain, and remove or reclassify the manifest entry in the same commit. No Render variable, database override, query flag, or Launch Control key may promote a design.
