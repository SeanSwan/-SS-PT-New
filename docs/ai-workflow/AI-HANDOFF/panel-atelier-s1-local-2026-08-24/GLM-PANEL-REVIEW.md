## ATTACKS

(c) If the still graph's seed node isn't wired via `SWAN_COMFYUI_NODE_SEED_*`, ComfyUI randomizes → "reproducible" assets aren't. (d) NFC/NFD brief variants hash differently → bucket bypass (minor). (e) STATUS-map hole: unexpected throws map to 503 "provider down" — a code bug presents as an outage, and `E_TASTE_UNREACHABLE` collides with the same 503, making taste-down and Comfy-down indistinguishable to monitoring. (f) Mid-batch law-filter rejections must reuse the existing per-image 207 failure buckets — unspecified. (g) Taste server returning fewer than `n` prompts → index-out-of-range/undefined prompt dispatch.
- **Security:** (a) SSRF — fetch URL must be a literal; params enumerated and encoded, never concatenated. (b) Prompt text (MJ-archive content) must stay out of logs — it's studio IP. (c) DoS — unbounded `count` on local is self-DoS of the studio's only GPU; taste server has no rate limit and the backend inherits none. (d) MCP agent misfire (stop/launch) is an insider availability attack. (e) Zero-PII rule: taste prompts are corpus content, not user data, but `assertLawful` is the control keeping celebrity/brand tokens out of hosted dispatch — which loops straight back to Blocker 2.
