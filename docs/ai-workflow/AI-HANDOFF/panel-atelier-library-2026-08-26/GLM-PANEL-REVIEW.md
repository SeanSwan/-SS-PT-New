## BLOCKERS
1. **P0 — Production SQL never executed once.** Scenario: any tag-filtered request (`Op.contains` on a JSONB array) where Sequelize binds the JS array as a PG array/text rather than jsonb → `operator does not exist: jsonb @> text[]` → 500 on every tag filter, forever, with 396 green unit tests. The same gap hides any keyset dialect error. Evidence: §7 "NOT proven: that the query executes"; §6.3 admits it. Shape assertions cannot catch a binding-type failure — that's precisely the class of bug shape tests are blind to.
2. **P0 — Owner scope can silently vanish at the JS layer.** The builder is `{ ownerUserId: userId }` and Sequelize drops any where-key whose value is `undefined`. Scenario: route mounted without/behind-failing auth middleware → `req.user?.id` → `undefined` → predicate omitted → **every tenant's assets returned**. The cited test (userId:7, ownerUserId:9) covers IDOR-by-param, not the undefined-drop; and the route/controller file is absent from the landed-files table entirely, so the middleware chain is unprovable. Evidence: §3 owner-scoping paragraph; §3 file table (no route file); `ContentStudioHub.tsx:183` shows the endpoint is called but not where it's served.
3. **P1 — Cursor precision vs. tie-break.** JS Date serializes milliseconds; Postgres timestamptz stores microseconds. Two rows the DB orders by µs-differing timestamps serialize to the same ms cursor, and the `(createdAt, id)` comparison mis-slices the boundary → skipped or duplicated rows — and the packet itself says same-ms rows are the *expected* case ("two stills from one batch share a millisecond"). Also: malformed client-supplied cursor → decode path unaddressed → unhandled throw → 500. Evidence: §3 cursor paragraph. (Downgrades to P2 if the column is ms-precision — not stated.)
4. **P1 — The motivating use case is unsolvable as shipped.** No thumbnail/URL (storage key withheld; card shows dimensions) and no prompt search → "find the glacier one" is impossible; you've shipped the index without retrieval. Note the withholding rationale is a false dichotomy: `provenance->>'prompt' ILIKE …` needs an index only to be *fast*, not to be *correct* — the packet already accepts seq scans for filters. Cheapest fixes: server-issued short-TTL presigned URLs (key still never leaves the server), and/or expose a prompt snippet in the client-safe view. Evidence: §3 storage-key paragraph; §6.5.
5. **P1 — The only cited type gate may not cover the integration point.** `tsc -p tsconfig.atelier.json` covers a 15-file glob of unstated scope; `ContentStudioHub.tsx:183–184` (the tab wiring) may sit outside it, and `vite build` does not type-check. Evidence: §7; glob pattern not shown.
