## What was decided/built (Fable-tier lesson)
Sean asked whether to MERGE the Swan World Engine (18-world creative catalog + factory) into the
Smart Lens OS (fail-closed runtime theming engine). Fable's ruling: merge as ORGANS, never soup.
The factory stays the imagination/marketing lane; the lens stays the only thing touching product
DOM; the bridge between them is DATA ONLY — a distillation step (world → recipe-seed JSON → human
taste pass → the existing five-entry add-a-style pipeline). Code imports across the boundary are
banned and test-enforced.

## Why (the rationale Hermes should carry forward)
1. The World Engine's own firewall (experience-mode.md §3) forbids live M4 experiences on product
   surfaces — dashboards are where clients log workouts; atmosphere may never cost a frame or a
   tap. So the fusion imports worlds' SOULS (palette ratios, atmosphere, typography leans) as
   bounded CSS data, never their live machinery.
2. Two working systems each have an authority chain and a QA regime; blending them creates a
   third thing with neither. A data bridge preserves both regimes and keeps the lens core
   portable to Sean's future sites.
3. User customization is safe only as ENUM/ID selection against server-validated bounded
   contracts (accent pairs pre-checked for contrast, allowlisted font pairings, catalog pattern
   ids) — never free-form CSS/colors. Tier-gating the knobs (FREE/GUARDIAN/CRYSTALLINE) turns
   personalization into an ascension surface, aligning delight with revenue.

## Reusable pattern / rule Hermes should apply next time
When two shipped systems tempt a merge: keep each system's law intact, define a one-directional
DATA contract between them, put human taste at the bridge, and enforce the boundary with a test.
"Organs, not soup." Also: any user-personalization feature = bounded enums + server-side
validation + fail-closed rendering; the locked state of a premium knob is itself a sales surface.

## Risks / guardrails
- Live M4 / canvas / autoplay in product = automatic REVISE (firewall restated in the blueprint's
  06-bans).
- Overlay may never touch action backgrounds, chart series (beyond the accent seam), or
  host-fixed zones.
- Rollout (F3) ships behind a runtime kill switch and a Sean ping — flipping live UX is never
  silent.
