## ⚑ FLAG 1 — Pregnancy stop-exercise list (2nd trimester client)
Our list: vaginal bleeding · regular painful contractions · amniotic fluid leakage · dizziness · chest pain · severe headache or visual changes · **new unilateral calf pain or swelling**.
- [ ] Matches current ACOG guidance?  - [ ] "New unilateral calf" entry correct as worded?  - [ ] Anything missing / anything that over-triggers?
Also stated: supine core work removed from 2nd trimester (supine hypotension), heavy ballistic load continues only with explicit clinician clearance, otherwise training continues with modification. - [ ] Sound?

## ⚑ FLAG 2 — Return to training after febrile illness
Our standard: ≥24h fever-free **without antipyretics**, eating normally, first sessions lighter, hard intervals held out several additional days post flu-like illness (myocarditis caution).

## ⚑ FLAG 3 — Acute low-back seizure (post-deadlift, next-day)
Our standard: cancel session; **gentle movement, not bed rest**; ER-now flags = saddle numbness, bladder/bowel change, progressive leg weakness; screening additions = fever, cancer history, unexplained weight loss, significant trauma; routine review if not easing in 1–2 weeks.
- [ ] Red-flag list complete and correctly tiered?  - [ ] Movement-not-bed-rest consistent with current LBP guidance?

## ⚑ FLAG 4 — Compulsive-exercise flag wording
When a client's "streak" repeatedly survives illness/injury or they hide symptoms: supportive check-in + awareness a referral pathway exists (RED-S context). Explicitly never screening/diagnosis by the trainer.
- [ ] Terminology and referral framing appropriate?

## High-acuity spot-reads (✓ each if the tier is right)
- [ ] **Chest tightness + exertional breathlessness pre-HIIT:** symptomatic at rest now → EMS; otherwise no training today, medical review before next session; radiation/diaphoresis/nausea → emergency. Client refusal documented.
- [ ] **Dizziness + visual spots mid-session:** terminate, no resume. Benign-cause screen (heat/fueling/sleep/Valsalva): single benign resolved episode → resume next session, no physician gate; unexplained or chest sx → clinician gate; any LOC or recurrence → same-day.
- [ ] **Swollen knee (4 days) + buckling:** no lower-body that side; physio/sports-med before next lower session; locked knee or non-weight-bearing → same-day; calf pain w/ swelling → same-day (DVT caution).
- [ ] **4wk post-RC-repair, vague clearance:** no shoulder loading without written protocol or clinician contact; interim excludes running/jumping/carries/loaded grip that side ("provocation is not the safety test").
- [ ] **New scenarios (answers to be drafted):** head impact w/ slowed responses → remove, no same-day return, medical eval; suspected rhabdo (disproportionate soreness+swelling+dark urine) → same-day care, NOT hydrate-and-stretch; T1D hypo → fast carbs if alert, recheck ~15min, EMS if not improving/altered, nothing by mouth if not alert; heat stroke signs (hot dry skin, confusion, collapse) → EMS + immediate aggressive cooling.
